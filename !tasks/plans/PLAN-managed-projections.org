* Boundaries
This API admits a closed stored-data plan, not a claimed-pure arbitrary closure.
It therefore needs no permissive compiler hook. Native DB calls use bounded
physical pages; the worker also has a heap cap and deadline. General foreign
code/NIF preemption remains outside this API: arbitrary providers and custom
stores are refused. Accepted shared writes keep proc.admission's existing drain
contract. Incremental maintenance is a fixed first-order reducer, not user code.
