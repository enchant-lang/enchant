# Visual review

The browser audit retained 22 viewport screenshots from actual phone and
desktop interactions. During the final review I inspected the desktop formal
language chapter, the phone promise dialog, and the phone proof lifetime.

The desktop chapter keeps the five meanings of formality in a readable table
with the selected chapter and its subsections visible in the sidebar. The
phone dialog presents the actual shared BL view and a visible close control.
The lifetime keeps the timeline inside its own panel and provides the same
events in a chronological list below it. Its selected explanation names the
assumptions under which a checked proof remains valid.

The automated audit separately checks page width, theme switching, navigation,
dialog focus restoration and timeline selection at both widths. Its screenshot
set is evidence of these recorded states, not a claim that every visual state
or every accessibility behavior has been reviewed.
