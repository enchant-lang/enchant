** Let each kind of evidence say exactly what it checked
A solver can report that a counterexample does not exist. BL can check a concrete point. A separate checker can establish a small finite theorem. These are useful answers to different questions, and the shared interface now keeps all three visible.

The [[#cell-story-word-evidence][word example]] asks both engines about the same three-bit wrapping rule. Their UNSAT reports remain solver claims. A handler can instead supply an ordinary certificate candidate: BL derives all eight values itself, checks the original proposition and keeps the exact assumptions beside its conclusion. That path opens no solver. The mathematical statement can be reused when you switch the requested backend.

#+begin_rosetta :title "Read the answer without guessing"
Evidence | What it establishes | What it does not add
Native UNSAT | What this engine reported for this request | An independently checked proof or authentic saved execution history.
Valid point | The original conditions hold at those coordinates under the named point policy | A universal theorem or a compiler connection.
Finite certificate | The conditional word statement checks over every valuation in its admitted small domain | Feasible premises, a mechanically verified checker, or ordinary program correctness.
Budget refusal | Checking did not run or did not finish within its allowance | A false mathematical proposition.
#+end_rosetta

The proof allowance belongs to the caller. A zero allowance leaves the proof incomplete; it does not change the theorem. Saved bundles retain the original request and candidate data, and reopening runs the checks under the reader's current allowance. An old saved success is not accepted as a checking result.

** Give text positions a precise meaning
The [[#cell-story-scalar-text][text example]] uses a base letter followed by a combining accent. It occupies three UTF-8 bytes, two codepoint positions and one BL grapheme. A formal text interface must say which of those it counts.

#+begin_rosetta :title "Choose the result you mean"
Operation | At an invalid codepoint position | Meaning
at-total | Empty text | The total SMT convention.
at | None | An explicit Option, separate from Some empty text.
at! | Formally undefined | A deliberately strict accessor.
at-or | Your supplied fallback | An explicit alternative.
#+end_rosetta

The same symbolic contract reports UNSAT in Z3 and UNKNOWN in OxiZ. Concrete BL replay agrees with the stated combining-character result. The term interface stays the same; the capability difference stays visible. Ordinary BL String operations keep their existing behavior.

#+begin_honest :title "The text domain still needs a connection"
The checked point representation accepts valid UTF-8 scalars up to 0x2FFFF. The specified SMT String alphabet is broader: its interval includes surrogate codepoints that UTF-8 cannot encode. Domain metadata does not constrain a native quantified variable. A checked relation between these domains is required before translating general host-text proofs. Native String results remain claims here.
#+end_honest

** A conditional proof still needs usable premises
An impossible precondition can make a conditional theorem true. It does not give you a usable program input. The next BL interfaces now check that distinction in code, separately from the selected runtime's finite checker.

#+begin_rosetta :title "The next boundary, exercised as separate BL code"
Interface | Actual check | Current boundary
Finite premise feasibility | 35 assertions: derive the exact background, then check a satisfying point or a contradiction | An isolated prototype; the installed finite checker still reports feasibility unestablished.
Obligation policy | 93 assertions across allow, report and reject, with fresh checks when a saved candidate is reopened | An isolated prototype; ordinary SDK query readers still need the coordinated vocabulary change.
Graph integer certificates | 54 assertions: unbounded linear-integer entailment, checked weighted rows and shared formula/proof graphs | Linear-only prototype; piecewise integer choices, wider rules and the common proof dispatcher remain next.
#+end_rosetta

The integer checker bounds its coefficient representation and checking work. It does not enumerate or bound the logical integer inputs. Its shared-argument example checks eighteen typed nodes while the original graph describes more than a million expanded occurrences. Neither this result nor the finite word checker establishes ordinary BL compiler correctness.

Contract preconditions already enter the explicit assumption ledger. That is where a feasibility check belongs; arbitrary implication antecedents remain mathematical formulas.
