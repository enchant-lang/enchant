# Keep the saved evidence view separate from logical authority

The latest committed dossier snapshot is frozen at
`5a1679cff66e87f5f51384b250b4c0be4fc406e5`, including the new `research.elements`
contract. Its source is captured under the word presentation's immutable kit
pin. The existing host still uses its preceding qualified kit; activation and
browser qualification are pending. Foreign working edits remain untouched.

This is the implementation contract for the next evidence-view slice, rather
than a claim that its renderer or browser saves already exist. Finish selecting
the word SDK before modifying the existing project review-host modules captured
by its regression/native source pins.

The question is concrete: **what does the evidence establish about this word
answer?** A comparison should distinguish the exact complete subject, native
reported status, independently replayed point, resource refusal, checked proof
support and Source/compiler connection. Every displayed fact needs an artifact
revision and exact locator. A missing support receipt stays unknown or pending;
it is not evidence that a theory is impossible.

Use three interfaces:

1. A product-owned pure producer reads a fixed, bounded set of actual qualified
   artifacts and the immutable SDK descriptor. It emits finite comparison data
   through `research.elements/element`. The question, scope, recorded period,
   source hashes, evidence locators and producer/renderer versions are retained.
   Mark these as actual implementation observations, rather than accepting the
   helper's default fixture-origin label. Never execute a payload or choose a
   callable from data.
2. A single installed comparison renderer serves tool output, the dossier,
   workspace view and component specimens. The project host attaches the known
   pure function through its existing `:render-block` extension. Only its fixed
   element identity and renderer ID resolve through the product authority.
   Other renderer IDs remain unsupported source data. The new public-sharing
   routes and private publisher configuration are separate features.
3. An owner-authorized store appends snapshots as native
   `#+begin_research_element` records. It preserves prior revisions, compares
   the saved basis with current sources and offers explicit save/refresh.
   Reopening never silently substitutes a new answer. A saved view does not
   establish logical validity; stale source basis does not refute a theorem.

The record must retain the question, exact SDK/semantic scope, period, source
basis, source locators, renderer/function identity and version, finite result
and snapshot identity. Original packet or assumption references remain data;
owner-local native IDs and short-lived callbacks do not become portable meaning.
Research `:supported` means a located evidence statement. It never upgrades a
native claim to a checked certificate or creates compiler authority.

Use existing dossier visual primitives and the current design. Show the
comparison before its provenance details; make each source inspectable. Keep
pending proof/Source capabilities visible. A source-backed relation needs its
own exact evidence and temporal bounds, with candidate/disputed relations
separate. No score, co-location or absent artifact becomes a negative fact.

Qualification must exercise actual native record traversal and source locators,
period bounds, unsupported facts, rejected renderer IDs, exact Org round-trip,
changed-basis reopening that retains the prior snapshot, explicit refresh and
a real durable save through the browser. Browser controls resolve a fixed
product element ID; they cannot supply a source path or executable function.
If an editable Enchant projection is later installed, adapt its descriptor to
the actual `live.edit.app` authority and qualify that editor separately.

The full word dossier still needs the real writer, independent unchanged check,
new host/kit identity, both viewport sizes and themes, and inspected actual
frames. Neither this contract, the source snapshot nor a green layout count
substitutes for that qualification.
