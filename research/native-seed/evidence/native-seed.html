use-joltdecided

Borrow the design; keep bl-ANF

✓BL-owned Scheme emitter and explicit host ABI.
·Translate BL into Jolt's Clojure frontend or its different IR.

Jolt does not consume bl-ANF. Reusing its complete runtime would require a value/namespace/callable compatibility layer. The existing BL compiler and JavaScript actor kernel already define the semantics we need.

Jolt architecture and bootstrap gates · Jolt host adapter semantics · Jolt backend maturity · Chez compiler · Gambit targets

Jolt's Gambit adapter is documented as demo grade, with native compilation and FFI capability degradation. Gambit's own C compiler is a separate capability; this experiment uses it directly.

Self-hosted compiler and independent runtime are different gates

A BL compiler that compiles itself through Scheme is self-hosted while still using Scheme's compiler and GC. Removing Scheme also requires replacing its value layouts, allocator/GC, continuations, exception unwinding and host ABI. LLVM does not supply those language/runtime services.
