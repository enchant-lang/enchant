#+begin_honest :title "What this first slice establishes"

* What should we borrow from Jolt?
#+begin_rosetta
Route | Verified upstream capability | Consequence for BL
Jolt → Chez | Self-hosted Clojure compiler; Scheme emitter; native compilation | Borrow the emitter/adapter split and seed fixpoint gates.
BL → Chez | Chez compiles Scheme directly to native code | Useful native route; it does not provide a C or LLVM output stage.
BL → Gambit → C → LLVM | Gambit has a C target; Clang emits LLVM IR from C | Chosen seed route. Generated units still require Gambit's runtime.
BL → LLVM directly | Proposed | Needs value layout, GC roots, tail calls, suspended frames and exception ABI first.
#+end_rosetta

#+begin_decision :id use-jolt :title "Borrow the design; keep bl-ANF" :status decided :answer "Agree" :by "conversation"
- [x] BL-owned Scheme emitter and explicit host ABI.
- [ ] Translate BL into Jolt's Clojure frontend or its different IR.
Jolt does not consume bl-ANF. Reusing its complete runtime would require a
value/namespace/callable compatibility layer. The existing BL compiler and
JavaScript actor kernel already define the semantics we need.
#+end_decision

* How does one message move?
#+begin_sequence :title "The same BL receive policy, a different execution host"
lanes sender · compiled BL | mailbox · BL runtime | receiver · Scheme frames | clock · virtual seed host
receiver -> mailbox : scan queued messages in arrival order
mailbox --> receiver : no matching message; retain scan cursor
receiver -> clock : compute one deadline
receiver -> mailbox : register waiting state atomically
receiver -> receiver : park; retain one-shot continuation
sender => mailbox : append a message; mark receiver runnable
mailbox -> receiver : resume and scan before checking timeout
receiver -> mailbox : remove only the selected message
receiver -> receiver : invoke the compiled clause body
#+end_sequence

#+begin_honest :title "Self-hosted compiler and independent runtime are different gates"
A BL compiler that compiles itself through Scheme is self-hosted while still
using Scheme's compiler and GC. Removing Scheme also requires replacing its
value layouts, allocator/GC, continuations, exception unwinding and host ABI.
LLVM does not supply those language/runtime services.
#+end_honest
