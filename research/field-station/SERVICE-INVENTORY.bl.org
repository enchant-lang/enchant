* Existing wiring that must survive
The workstation already compiles a closed deploy/intent.bl through
workstation.deploy.declaration into a deterministic native Nix projection,
binding source/compiler digests. It separately selects general, pool and
controller runtimes; legacy instance adoption is deferred rather than guessed.
Extend this contract after application qualification instead of replacing it.

Messages already has native recursive Datom topic relations and signed actor
sessions, but the authoritative domain writer is SQLite in a Python broker.
Move that authority to native transactions rather than keeping the current
Python/BL projection bridge. Gateway, dashboard and the work CLI are already
Enchant consumers and should adopt library improvements rather than be rewritten.

The current local edits add NixOS dry-activation impact reporting and a health
manifest with local message/dashboard probes. Keep them. They do not establish
authenticated public-route health, complete service readiness or zero downtime.
