#+title: Field Station service prototypes

* Scope

Executable experiments for a Datom/proc-native workstation. State is private,
disposable, and separate from production. No production database is opened;
there is no SQLite runtime adapter and no remote deployment.

The initial implementation is awaiting native acceptance. APIs here are
prototype composition over existing Enchant namespaces, not new stdlib promises.
The native filesystem operation is descriptor-based file publication, not a
claim that the complete POSIX ACL service has been ported. The Unix test proves
SO_PEERCRED and framing within this OS process; it is not a cross-user isolation
rehearsal. Authorization identities in namespace tests use explicit TEST ingress.

* Run

From this directory: =./run core=. The launcher caps one cold VM and preserves
the log and JSON receipt in a private directory below =$HOME/tmp=. It stops its
owned service on exit. It never stops unrelated VMs.

* Prototype sets

1. EDN export to real Fjall-backed Datom: chunk receipts, interruption, reopen,
   exact resume, identity/content verification and changed-export refusal.
2. Existing checked namespace grammar bound to a Datom inbox and atomic claim
   transaction: current membership, request identity and audit in the writer.
3. Real AF_UNIX connection with kernel SO_PEERCRED, bounded length framing and
   a forged identity payload that cannot change the kernel principal.
4. Datom query watch and proc reconciliation to a native pinned directory:
   lost-result recovery and change-driven desired-state publication.
5. Veritas generated histories over real stores, with a durable verdict ledger
   and explicit refusal to promote sampled evidence into proof authority.

Foundry/Nix generation integration is the next connected prototype set.

* Important bounds

The EDN snapshot is bounded to 8 MiB and 10,000 records. Import is into an
unselected destination and does not establish whole-host writer fencing.
Verification currently covers message identity/body/time; attachment and full
production triage migration require additional application-specific checks.
Inbox results are fixture-sized: production indexed pagination and query work
budgets are not claimed by this prototype. Model checking samples sequential
histories; independent concurrent and OS crash tests remain separate evidence.
