#+title: Field Station prototype acceptance — 2026-11-16

* Qualification boundary

These are executable experiments over disposable local state, not production
service replacements. Nothing activates a workstation configuration, opens a
production SQLite database, sends inbox messages or deploys a remote host.
There is no SQLite compatibility layer. The import begins from a bounded EDN
snapshot and ends in native Fjall-backed Datom.

All substantive native checks run serially with a 3 GiB memory ceiling and
512 MiB swap ceiling, and their owned systemd units are stopped on exit.

* Reuse and promotion

The useful service-level abstraction is a checked namespace linked by the host,
with Datom authorization/query projections and command transaction functions.
The service does not need its own role cache, SQL repository, retry database,
event bus, actor framework or Python-shaped subprocess wrapper.

Keep OS effects behind native capability boundaries. The Unix prototype proves
kernel credentials and bounded frames; promoting it requires a supervised,
bounded acceptor plus cross-user tests and connection-to-principal host wiring.
The filesystem prototype proves descriptor/CAS publication; it does not provide
the complete ACL service or establish whole-host ownership fencing.

Use Datom desired revisions plus existing proc reconciliation for durable work.
Keep observations as facts and stream process output through demand-aware flows.
Turn only the resulting stable compositions into stdlib conveniences; these
experiments introduce no new language syntax or parallel infrastructure.

Nix owns controller package, identity, directories, ports and candidate closure.
Foundry owns admitted release identity, selected generation, native store sharing,
publication, draining and durable recovery. A production deployment command must
combine both receipts and verify the selected generation through the real service
route before returning success. A successful Nix switch alone is insufficient.

* Remaining qualification

Historical failed runs are preserved separately from the passing final receipt.
The unavailable constructor and queued-exit shutdown defects are fixed and the
full publication-to-cold-restart gate now passes on the pinned Foundry commit
=ebd3b559551b8b5c355ebb5c189a66c099838dce=.
An earlier same-VM stop/recreate experiment failed managed bootstrap
(=foundry-same-vm-restart-failure.json=); that independent scenario was not rerun
and is still unqualified. Cold OS-process recovery is qualified by =foundry.json=.

Complete the real packaged controller contract, boot a NixOS rehearsal,
exercise slow clients and accepted work across publication, kill/restart at
publication boundaries, verify rollback and generation-specific HTTP/WebSocket
behavior, and test topology handovers separately from source-only updates.
Replacing the controller/SDK changes the Nix unit and currently restarts it.
Zero downtime across that boundary needs a separately qualified stable socket
front end, old/new runtime handover and exclusive Datom writer transfer. The
same-VM source publication experiment does not establish that capability.

The command experiment bounds capture before applying proc demand processing.
It does not backpressure the OS producer. A future live subprocess producer
needs a supervised port owner, independent deadline/cancellation and bounded
credits, using the same group-lifetime primitive rather than another subprocess
framework.

The importer must still receive a production-specific SQLite export script and
complete verification for membership, recipients, attachments, triage and other
application facts. It is bounded to 8 MiB/10,000 records and writes an unselected
destination; it does not fence a live production writer or prove arbitrary-scale
query latency. Veritas results are witnessed histories, never compiler proofs.

The Foundry =runtime/bl= fixture is an explicit never-executed identity marker.
The actual managed server runs in the retained SDK. No portable runtime package,
TLS ingress, cross-user Unix isolation, complete ACL migration or production
rollout is qualified here.

The build-station protocol currently buffers detailed remote build output until
completion. Each host-module change rebuilt all 640 library units (about twelve
minutes in the producer, plus orchestration). No speed ratio is claimed. Progress
streaming and narrower qualified cache invalidation remain useful build-workflow
improvements, distinct from the deployment progress exercised here.
