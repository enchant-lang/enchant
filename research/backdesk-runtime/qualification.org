#+TITLE: Backdesk retained-definition storage controls
#+DATE: 2026-11-16

* Problem and change

Backdesk's fresh-store profile on v2026.11 retained about 101 MiB in the Env
registry, including roughly 86 MiB of expanded emitted-definition terms.
Loading/compilation/byte validation dominated pre-ready CPU samples. This is
runtime metadata, separate from the application's hotel records.

Commit =5ceb03aab= retains the registry's exact term model using ETS compressed
storage. Keys remain indexed, and existing native lookup, matching, ownership
and generation-counter semantics are unchanged. It also authenticates the
actual artifact bytes in =Env.sdk_image_metadata!=, removing the duplicate
complete-artifact hash in =AOT.image_sdk_entry!=. Metadata cache hits still
validate actual bytes. Decoder identity and the complete descriptor still
scope cache entries; no filename, mtime, digest hint or caller flag grants reuse.

* Refinement after application profiling

The first whole-registry prototype is superseded. Its Backdesk source run
reached the 240-second sampler deadline before readiness, at the store-open
stage. Its memory observations and 241 passing checks do not establish an
acceptable application-startup result. Additional queued prototype package
checks were cancelled before starting.

=1f7b1a46e= restores ordinary registry storage and compacts ONLY emitted
publication receipts. Version 3 stores bounded ETF data containing the complete
version-2 receipt; it does not replace evidence with a digest. Publications
validate inert data before and after materialization, then retain the original
stored receipt in their checked snapshot. Private cached observations compare
that exact row and keep all declaration, actual-code and generation checks.

The decoder checks the envelope, byte limit and compressed uncompressed-size
header before safe decoding. Receipt data exceeding the packing budget retain
the legacy representation, so ordinary compilation does not acquire a new size
refusal. Tests exercise descriptor forgery INSIDE encoded payloads, opaque
values hidden in payloads, corrupt/oversized headers and exact receipt recovery.
Ordinary variables and generation counters never pass through this codec.

The final-source SDK build and nine focused suites are pending. Do not activate
the whole-registry prototype or cite its fixture reduction as final app savings.
