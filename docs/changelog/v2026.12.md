# Beam Lisp v2026.12

This release makes `bl` much faster to use and to build: warm commands answer
in tens of milliseconds, a cold start takes about a second, library edits run
without an SDK rebuild in a checkout, and an SDK rebuild restores unchanged
units. It also makes numeric equality and collection keys value-based, turns
`require` into a function, and serves projects in development mode by default
with an authorized in-app inspector. It adds tables, drafts and code services
to the document editor, authenticated namespace imports, Unix RPC and command
custody, binary64 Float reasoning in the formal tools, and an Android scenario
world.

[Complete commit list](https://github.com/enchant-lang/enchant/compare/v2026.11...v2026.12)

## Speed

Measured on a drop built from the release commit, against the drop that was
installed on the same host (build `f5ee4ce9`, 2026-11-02). Runs were interleaved,
with the load recorded: 15 pairs at load 10–14 unless noted.

- **Warm commands.** A project's warm `bl run` takes a median 27 ms
  (16–37 ms), down from 270 ms. `bl eval '(println 1)'` takes 10 ms, down from
  162 ms. A request runs in its connection's process, the client makes one
  exec, and unchanged forms replay without recompiling.
- **Cold start.** `bl --cold run` takes 1.4 s, against 5–64 s for the old drop in
  the same session under swap pressure (2.6 s on a quieter host).
  The boot state is sealed into the SDK, and the owner registry and the SDK lease
  start lazily with the first managed actor. On a quiet host a cold
  `(println 1)` takes about 1.05 s.
- **Project edits.** After an edit, unchanged project namespaces are restored
  when a realm retires, instead of being recompiled. An unchanged warm
  `bl test` of one file takes about 135 ms. A body edit then `bl test` takes about
  300 ms, down from 450–500 ms.
- **Library edits in a checkout.** An edited `priv/lib` or `priv/std` file
  (outside the compiler-key set) runs in the warm VM about 1 s after the edit,
  without an SDK build. Units whose servers are running stay on the SDK's code
  and are reported once. `BL_CHECKOUT_DEV_OVERLAY=0` turns this off. Installed
  drops and ordinary projects never use it.
- **Checkout commands.** A warm `./bin/bl run` takes 6.6 ms, down from 25 ms.
  The client's own `.bl/bin/bl` takes 4.7 ms. `./bin/bl --cold` adds 55 ms over
  the SDK's own cold path, down from 570 ms.
- **SDK builds.** A `priv/host` edit takes about 11 minutes, down from about
  42: library units are reused when their compile-relevant inputs match (668 of
  668 restored for a host comment), and restored units are linked rather than
  copied. A `priv/boot` edit takes about 29 minutes, down from 50, because the
  bootstrap starts from the previous qualified compiler and the third
  generation is skipped when the second already proves the fixpoint.
- **Fixes along the way.** A fresh VM no longer fails 1 start in 3 with
  `already_started`. `bl realm stop` now waits until the VM has gone, so the
  next command cannot reach a stopping VM. A warm VM that dies at start fails the
  request at once with its log tail. A failed SDK preparation names its first
  cause.

## Language and runtime

- `=` compares exact numeric values: `(= 1.5M 1.50M)` is true, and
  `(= 0.1M 0.1)` is false because it uses the Float's actual IEEE value. The
  new `decimal/same-representation?` compares coefficient and scale, like
  `BigDecimal.equals`. Printing and arithmetic still preserve scale.
- Collection keys follow `=`. `get`, `contains?`, `find`, `dissoc`, set
  construction, sorted collections and transients canonicalize numeric keys,
  so `(contains? #{1} 1.0)` is true. Decimals sort among the other numbers.
  Raw Erlang map operations keep exact keys.
- `require` is a function. It applies `:as`, `:refer`, `:as-alias`, prefix
  lists and `:reload` to the current namespace. Every check runs before
  anything is written, and errors include near-miss suggestions. Literate
  `.bl.org` and `.bl.md` modules load like `.bl` files.
- Core adds `all-ns`, `find-ns`, `ns-publics` and `ns-aliases`. The new
  `clojure.repl` provides `apropos`, `dir`, `source` and `source-fn`. `source`
  returns the original definition text, including from literate files.
- Lazy values detect cycles when they are forced. A value that only embeds its
  own node is data. Cross-process lazy waits also observe the owner's exit.
- `clojure.edn/write-string` writes finite EDN for persistence. It never
  abbreviates and orders maps and sets deterministically. It refuses functions,
  lazy values, opaque host values and nesting deeper than 256.
- Fixes: nested `doseq` effects run correctly, and a retired local lock wakes
  every queued waiter. Org documents expose nested spans and comments without
  executing literal blocks.

## Command line and project configuration

- `bl serve` runs in development mode unless the project's `:loading`
  environment selects production. `--no-dev` turns off the inspector for one
  launch, and `{:devtools false}` in `env.bl` turns it off for every launch.
  The portable drop defaults to development when `BL_ENV` is unset.
- `bl check --quick FILE` reports reader errors and repeated definitions.
  `bl codebase FILE` lists top-level definitions and direct imports.
- `env.bl` `:tools` names Nix installables. `bl.tools/executable` builds a
  tool on first use against the project's locked nixpkgs and reuses the store
  path. Declaring a tool runs nothing.
- `env.bl` `:source/imports` imports content-pinned source bundles from other
  repositories. Pins cover the manifest and every listed file, and are computed
  with `bl.source-imports/fingerprint`. Bundles are read as EDN, never
  evaluated. Path traversal, symlinks, namespace collisions and SDK
  replacements are refused.
- `env.bl` `:auth/imports`, `:auth/realms` and `:auth/realm` declare
  authenticated namespace imports (see below). Invalid declarations are
  reported with the other configuration errors.
- Loader progress goes to stderr, so application output stays
  machine-readable. Positional arguments after development flags are kept.
- In a checkout, a command waiting for another caller's SDK preparation prints
  the owner and its progress. `BL_SDK_LOCK_WAIT` limits the wait (exit 75),
  and `BL_SDK_REUSE_CURRENT=1` uses the current published SDK instead.

## REPL, harness and analysis tools

- The web REPL shows the arglists of the enclosing call, completes namespaces
  inside `(require '[`, displays missing closers as ghosts, and underlines
  advice smells. Side panels show what has been required, a record for each
  namespace and var, and harness tasks.
- `harness.repl` adds `task`, `say`, `note`, `keep!`, `rerun`, `await`,
  `stop!`, `tail` and `tasks` to the prompt. After each turn, advice on the
  `.bl` files the turn edited is added to the session.
- New harness sessions are `.bl.org` documents. Existing Markdown sessions
  keep their format, and `:format :md` selects Markdown.
- `deodorant.advice` and `defadvice` define smells that are explained but
  never auto-fixed. The first, `fixed-sleep`, flags `Process/sleep` in tests
  and browser/scenario code. `^{:smell/allow {:fixed-sleep "reason"}}`
  allows it.
- `system.inputs` finds the inputs a function reads in its code, including
  through dispatch tables and callbacks.
- LSP completion includes lexical bindings, function-valued callees and
  declared imports. The server releases document memory when the editor
  closes stdin. MCP stdio uses UTF-8 in both directions, and responses keep
  qualified fact keys and values.

## Development inspector

- `live.app/serve` accepts `:devtools {:authorize developer?}` and adds a
  collapsed dock for authorized developers. Other viewers see the original
  page, and inspector assets return 404.
- The dock shows Live page updates, Loom spacing, colours and corners, real
  `check`/`codebase`/LSP tool runs with cache reuse and admission waits, and
  the status of registered work owners. It also shows the serving VM's Beam
  Lisp and Erlang/OTP versions.
- Server can copy a report of the SDK identity, timings and counters. The
  report leaves out paths, symbols and source text. Receipt links connect
  projection status and tool runs to their recorded decisions, and
  `:source-link` lets an app link source locations to its own editor.
- `live.observatory/attach` mounts an authorized development view at
  `/__enchant`. Its JSON endpoint and `snapshot` share one bounded observation
  model. The inspector reopens after browser Back.

## Live and web

- Pages restored from the browser's back/forward cache suspend and resume their
  existing socket session and resynchronize.
- Initial mounts that were never delivered are recovered. SSR text boundaries
  and restored text layout survive patches and remounts. Inert `<template>`
  contents render the same way as in HTML hydration.
- Fragment links use native browser navigation, and `#fragment` is no longer
  part of route or query parameters.
- `web` before-send callbacks run under the request's execution admission, and
  abandoned responses are released. WebSocket callbacks keep their admission.
  Outbound HTTP keeps one absolute deadline across startup and streamed
  responses.

## Document editor

- Typed `table`, `table-row` and `table-cell` blocks support structured row and
  column commands, shared menus and Org-style keyboard navigation. Tables also
  support header state, rectangular selection and clipboard, and whole-table
  indent, and fit phone-width screens.
- Rich HTML copy keeps list hierarchy and nested tables, and paste imports them
  as child blocks. Mixed table fragments are refused rather than partly
  dropped. Pasted inline functions are normalized through their contract.
- Retained drafts are scoped to the actor and listed across tabs. Unreadable
  drafts offer a download, and discarded drafts are retired. Unrecognized text
  and recovered property fields stay available until explicitly discarded.
- Source editing preserves exact bytes and untouched line endings. Source-backed
  text subranges are editable, and validation errors stay correctable. Packages
  can export the current draft as source, and export is reachable by keyboard
  with a recovery copy.
- Code blocks offer completion, definitions, references and guarded edit
  previews. Language status survives a repaint.
- Packages gain parameterized commands with their own descriptions, command
  policies, keyboard radio groups for enums, caret previews and sibling context
  for renderers. Checklist splits keep task attributes, the media editor saves
  managed paths and URLs, and floating surfaces follow the Live theme.

## Data, Datom and projections

- `data.projection` manages shared, demand-driven reads. It provides `start!`
  for closed queries of up to eight stored Datom patterns, `start-incremental!`
  for event histories, and `reader` and `status`. Reads are metered and
  bounded, and an exhausted read reports an explicit blocked status.
- `data.first-order/encode!` and `decode!` exchange bounded native data (maps,
  vectors, sets, symbols, numbers and strings). They refuse compressed frames,
  functions, PIDs, ports, references and unknown atoms before allocating them.
- `datom.time` overlap and chronology questions run through `formal.temporal`
  with `:z3` or `:oxiz`. `overlap-result` and `consistency-result` return the
  full evidence.
- The Fjall store refuses oversized point reads and invalid key lengths without
  poisoning the store. Native lock files are released when their stores close.
  Offline digests no longer depend on persistent vector layout.

## Authentication, RPC and processes

- `auth.totp` implements RFC 4226/6238 authenticators: `secret`, `code`,
  `matching-counter` (for replay rejection) and `uri`, with percent-encoded
  labels.
- `auth.password` hashes new passwords with 600,000 PBKDF2-SHA256 iterations.
  `needs-rehash?` identifies older verifiers to upgrade after a successful
  login.
- Authenticated namespace imports let a project call a checked API owned by
  another realm. Each call rechecks the provider's authority, and native Datom
  values pass through without JSON conversion. Remote credentials require TLS.
  `examples/namespace-world` has five runnable example sets.
- `rpc.unix` serves and calls checked namespaces over Unix sockets. The caller
  is identified by its kernel peer UID through `auth.unix`.
- `proc.command/run!` runs an absolute executable in its own systemd domain
  with time, memory and output limits. It applies credit-based output
  backpressure and accepts private binary stdin.
- `proc.server` keeps its initialization state and optional timeout during
  clause expansion.

## Formal verification and Veritas

- `formal.beam-float` models Float as IEEE binary64. Veritas generators and
  source properties over Floats use this model, and NaN observations are kept
  apart from semantic NaN values.
- Veritas quantifiers, source properties and clause coverage run as typed term
  questions. Counterexamples are replayed against compiled code. The new
  `text-of` generator joins the existing generators.
- `veritas.mock` contracts support typed response relations, measured faults
  and integer boundary search.
- `formal` adds versioned public-data graphs, graph-backed questions with
  durable verdicts in the Veritas ledger, closed migration claims, checked
  affine query plans and portable temporal values.
- `effect` adds registered callable effect scopes that inherit a snapshot.
- SMT translation of `mod` keeps the divisor's sign.

## JavaScript target

- Compiled JavaScript can call portable host functions: rounding, integer and
  float parsing, math, calendar days, URI forms, string trimming, hex encoding,
  `Regex.split`, pure `Path` functions, and System and Application environment
  lookups. BEAM-only calls such as `File` compile to explicit refusals.
- JavaScript builds load literate namespaces and `bl.json`, and link EDN and
  source regex operations.
- Decimal supports named operations, exact terminating division and two-argument
  rescale. Equality and collection keys match the BEAM. `-0.0` keeps its sign
  in printing and negation, and a namespace's own definition shadows a Core name.

## Android

- `scenario.android` drives a phone or emulator over adb. It reads the
  UIAutomator tree, taps by label, types, swipes and waits, records a frame
  for each step, and can record video. Queries match `:class`, `:editable`
  and `{:below Q}`. `:scroll-to` searches upward too, and every adb call has
  a time limit.
- The template ships a foreground service, controlled by
  `android.foreground/start!`, `update!` and `stop!`.
- Accessibility scans expose more metadata, and Mob plugins start through the
  supported lifecycle API.

## Upgrading

- Checkout commands keep one warm VM per tree, and it now restores project
  units across realm retirement. `BL_REALM_UNIT_RESTORE=0` turns restoring off.
  `BL_REALM_UNIT_TIMES=1` prints each unit's key, fetch and restore times.
- Caches use new file names where their format changed (for example
  `~/.cache/beam-lisp/checkout-digests-v2/`). The October drop and this release
  can share one cache directory: both were run alternately on one cache, cold
  and warm, with correct output. The old `checkout-digests.v1` file is no longer read
  and can be deleted.

- `=` on numbers now compares exact values. Code that used `=` to tell `1.5M`
  from `1.50M` should use `decimal/same-representation?`. Comparing a Decimal
  with a Float uses the Float's binary value, so `(= 0.1M 0.1)` is false.
  (1f5dfe77c)
- Maps, sets and sorted collections built through Beam Lisp treat `1`, `1.0`
  and `1.0M` as the same key, and sorted collections order decimals with the
  other numbers. (e1f2552e4, c4d733726; JavaScript: e5928c521)
- `bl serve` enables the development inspector by default outside production.
  Use `--no-dev` or `{:devtools false}` to turn it off. The portable drop
  treats an unset `BL_ENV` as development. (414c044ba, 1fd067a3c, 202f3ba05)
- New harness sessions are written as `.bl.org`. Pass `:format :md` to keep
  Markdown. (63c1a4a1d)
- Loader progress is written to stderr instead of stdout. (91ff7e2a4)
- `datom.time/overlap-verdict` and `datom.time/consistent?` take an options map
  (backend `:z3` or `:oxiz`) instead of an open z3 port. `consistent?` returns
  `false` instead of `{:consistent false}` and raises on an unresolved answer.
  Use `consistency-result` to get the answer as data. (6b6ee6d86)
- `system.core/verify-process` returns `:unsupported` for Float or Real Source
  unless called with `:semantics :ideal-real-model`. That result is a model
  result, not a Source proof. Use `formal.source` with `formal.beam-float` for
  Float proofs. (bfa4cbe9d)
- `auth.password` creates verifiers with 600,000 iterations. Verification
  rejects verifiers with a different digest, more than 10,000,000 iterations,
  or a salt or hash of unexpected length. Existing verifiers in the standard
  format still verify. (f94cab3fe)
- Live routes no longer include the `#fragment` in the path or query
  parameters. (3328d5284)
- `veritas.mock/TIMEOUT-MS` and `veritas.mock/contract-decls` are removed.
  (646a7de8f)
