#+TITLE: Backdesk retained-definition storage controls
#+DATE: 2026-11-16

* Problem and change

Backdesk's fresh-store profile on v2026.11 retained about 101 MiB in the Env
registry, including roughly 86 MiB of expanded emitted-definition terms.
Loading/compilation/byte validation dominated pre-ready CPU samples. This is
runtime metadata, separate from the application's hotel records.

Commit =5ceb03aab= retains the registry's exact term model using ETS compressed
storage. Keys remain indexed, and existing native lookup, matching, ownership
and generation-counter semantics are unchanged. It also authenticates the
actual artifact bytes in =Env.sdk_image_metadata!=, removing the duplicate
complete-artifact hash in =AOT.image_sdk_entry!=. Metadata cache hits still
validate actual bytes. Decoder identity and the complete descriptor still
scope cache entries; no filename, mtime, digest hint or caller flag grants reuse.

The ordinary immutable Nix producer completed and its compiler P/B/C proof
passed. The runtime suites =sdk_image_metadata_test.bl=,
=system/publication_test.bl= and =native_execution_proof_cache_test.bl= passed
241 assertions across three files, with no failed or incoherent files.

The storage control inserted a nested clause/edge-shaped receipt, recovered
its exact term through both registry lookup APIs, and measured 295,376 bytes
of retained table storage against 1,212,792 expanded bytes (4.1× smaller).
Existing controls also cover changed artifact bytes/descriptors, forged raw
publication/definition/var rows without an epoch, live binding replacement,
readiness removal and retired definition evidence.

Additional variable-memo, application-package and boot-readiness checks are
queued against the same immutable SDK. Whole-application before/after startup
and retained-memory measurements remain separate qualification. This fixture
does not establish an application-wide 4.1× memory reduction or a boot speedup.

The related Backdesk change narrows ownership predicates from the whole host
context to a property key. Its two-property check measures 56 bytes per
predicate and preserves scope. Hospitality/retention suites passed 36 checks.
