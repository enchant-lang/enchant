* What changed
3243fec0d normalizes logical vectors before the offline inventory digest.
abf5d5548 and 700097b57 make explicit root close release child flocks even
while BEAM retains derived directory resources. Pins still refuse close while
a sealed or accepted publication owns the root.

The first SDK containing these changes revealed a regression: retaining every
native child descriptor in the root also retained source and sealed target
flocks after their explicit release. Existing source-claim and seal suites
refuted that behavior. d6efd00bf separates the two lifetimes: BEAM directory
handles keep root custody; native source/publication guards own their child
descriptors directly. The last native guard releases its flock without closing
the source root. Native publication pins still protect the root's lifetime.

The five Rust directory tests include retained handles, dropped BEAM handles,
pin refusal, identity failure, and native custody release/reacquisition. They
pass as five focused Rust unit tests (17 unrelated tests filtered out). The
immutable native source and its locked vendored dependencies are copied to a
private Build test tree. Cargo and rustc 1.98.1 run offline with two build jobs,
a 3G service ceiling, and no SDK producer. Actual runtime: 51.260s wall,
1m29.061s CPU, 695.3M peak.
